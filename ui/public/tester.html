    No server confirmation loaded.

    Measured v3 placement: shell level; lens centre 95 mm above the floor at the measured adjustable-feet extension; OPS centre 85 mm target-left, 47 mm forward and 20 mm below the lens; IWR RX-row centre 44 mm forward and 30 mm below the lens. OPS and IWR mounts point 10° up. The LIS3DH lies flat; the tilt check above finds which way round it is fitted and saves that for this unit (the shared rig file is never changed).

    Software verifies the selected config, each sensor's answer and the current tilt. It cannot inspect the enclosure build, feet extension, lens vertex or wiring. Deliberately tilted placements may cross the 2° flag: the warning is kept; correction accuracy is not validated. The admission check is not an attempt.
