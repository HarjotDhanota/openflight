OpenFlight camera mode study

Four camera modes, a 7-iron, five swings each. You collect; we analyse. This page never shows estimated club or ball numbers — only whether each swing saved usable, paired data. Exposure is set for you from physics; the gain step finds the light.

Before you start

  • Ball at address, unit placed the way you'll hit. The enclosure geometry comes from the checked-in file.
  • In the kiosk that opens for swing capture, select 7-iron once. It stays selected.
  • Keep the light the same for the whole session. If you change it, start a new tester ID.
