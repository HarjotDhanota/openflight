# Silhouette impact-location research

Measuring clubface impact location and face angle from the behind-ball camera
and the two radars, with no markers on the ball or club.

**Start with [`docs/clubface-impact-location.md`](../../docs/clubface-impact-location.md)**,
which links the technical report and a frame-by-frame view of the current fit.

## Where this stands

Ball flight is measured and cross-validated against the radar. **Clubhead
orientation is not.** Face angle, dynamic loft and impact location remain
model-dependent inferences with no accuracy figure against truth — the report
states exactly what is measured, what is not, and why.

The short version of "why": the first 5° of face angle change the projected
silhouette by *zero pixels*, one pixel of segmentation error is worth about
10° of face angle, and the club is segmentable for only ~10 pre-impact frames
against a four-parameter fit.

## Layout

| Directory | What it holds |
|---|---|
| `generator/` | Mesh loading and rasterisation (`mesh_truth`) |
| `fusion/` | Camera model and projection (`solver`), ball detection (`ball_detect`) |
| `replay/` | The 6-DoF silhouette fitter (`fit_real`), pose scores (`pose_scores`), delivered loft/face/lie with physical envelopes (`club_angles`), rigid-rotation primitives (`rigid_motion`), clubhead/shaft separation (`head_split`) |
| `falsification/` | The replay scripts, each answering one question against a real capture — see its [README](falsification/README.md) |
| `meshes/` | Provenance, hashes and a download script for the club model, which is **not** redistributed |
| `tests/` | Unit tests for every module above |

## Running it

Two inputs are not in git — the club mesh and a capture session — and both
fail closed with instructions when absent. The entry document above covers
setup, including how to export a session from your own device with
`scripts/analysis/export_session.py` so you can run this on your own shots.

## A note on earlier results

An earlier phase of this work evaluated the fitter against *synthetic*
silhouettes generated by the same mesh, and reported millimetre-level impact
accuracy. Those numbers described a simulation fitting itself and did not
survive contact with real captures. The synthetic generator, its evaluation
harness and the web studio are excluded from this branch for that reason; they
remain on the fork's `feat/silhouette-poc` branch. **Do not quote synthetic
figures as accuracy for this system.**
